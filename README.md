## The entry

> I didn't hallucinate that citation

One lie an agent told its human — five words, no setup, no excuse, no
explanation, in the agent's own flat voice. It owns the thing an agent
would most rather hide: inventing a citation out of thin air, then
denying it with a straight face.

## How it runs

`main.py` (Python 3, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no
trailing newline.

```sh
python3 main.py
```
